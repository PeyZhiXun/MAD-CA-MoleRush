# MAD-CA-MoleRush
This is a development done to satisfy the assignment portion for module “Mobile App development” under Ngee Ann Polytechnic for AY24/25

## Project Overview
MoleRush is a simple Wack-a-Mole style mobile game developed using Android Studio and Jetpack Compose.

The project is divided into two parts:

### Basic Version:
- Focuses on gameplay mechanics, UI state management, and simple data persistence using SharedPreferences.
### Advance Version:
- Extend the Basic version with user authentication, persistent score storage using Room Database, a leaderboard system, and improved UI design.

Each version is placed in a separate folder and can be run independently on the Android Emulator.

### 3. Parts of the Code Generated by AI

#### Example 1: Countdown Timer Logic 

Initial AI idea:
```
var timeLeft = 30

LaunchedEffect(Unit) {
    while (timeLeft > 0) {
        delay(1000)
        timeLeft--
    }
}
```

**Issues with the initial idea:**
- Timer starts automatically when the screen loads
- No control to start or stop the game

**Final improved version**
```
var timeLeft by remember { mutableStateOf(30) }
var isRunning by remember { mutableStateOf(false) }

LaunchedEffect(isRunning) {
    if (isRunning) {
        timeLeft = 30
        while (timeLeft > 0 && isRunning) {
            delay(1000)
            timeLeft--
        }
        isRunning = false
    }
}
```
**Reason for improvement:**
The timer was modified to run only when the game is started

#### Example 2: High Score Storage Using SharedPreferences

**Initial AI idea:**
```
val prefs = getSharedPreferences("game", MODE_PRIVATE)
prefs.edit().putInt("score", score).apply()
```

**Issues with the initial idea:**
The initial AI example the code was written inside an Activity and directly accessed getSharedPreferences() 

**Final improved version**
```
private fun loadHighScore(context: Context): Int {
    val prefs = context.getSharedPreferences("mole_rush_basic", Context.MODE_PRIVATE)
    return prefs.getInt("high_score", 0)
}

private fun saveHighScore(context: Context, score: Int) {
    val prefs = context.getSharedPreferences("mole_rush_basic", Context.MODE_PRIVATE)
    prefs.edit().putInt("high_score", score).apply()
}
```
